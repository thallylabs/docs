Set secrets in `.env.local` for local development and in the hosting provider
for deployed environments. Never commit real values. Legacy `DOX_*` names are
still accepted where a corresponding `THALLY_*` variable replaced them.

## Site and deployment

| Variable | Required | Purpose |
| --- | --- | --- |
| `THALLY_SITE_URL` | Production | Public origin used by canonical URLs, social metadata, sitemaps, and agent endpoints. |
| `THALLY_CONTENT_SOURCE` | No | `filesystem` for normal self-hosting; managed hosting can set `assets`. |
| `THALLY_DISABLE_BUILD_CACHE` | No | Set to `1` only to diagnose a bad persistent build cache. |

## Thally Cloud connection

| Variable | Required | Purpose |
| --- | --- | --- |
| `THALLY_CLOUD_SITE_TOKEN` | Connected self-hosted sites | Server-only credential issued by Thally Cloud. Never use a `NEXT_PUBLIC_` prefix. |
| `THALLY_CLOUD_URL` | No | Overrides the control-plane origin for staging or development. |
| `THALLY_CLOUD_SITE_CONFIG` | Managed only | Release snapshot injected by managed hosting. Do not set it manually. |

## Admin and visitor access

| Variable | Required | Purpose |
| --- | --- | --- |
| `THALLY_ADMIN_PASSWORD` | Recommended | Shared Owner password for `/admin`. |
| `THALLY_ADMIN_SECRET` | No | Separate signing secret; defaults to the admin password. |
| `THALLY_ACCESS_PASSWORD` | Private docs | Enables the shared visitor-password gate. |
| `THALLY_AUTH_SECRET` | OIDC or stored secrets | Signs sessions and encrypts stored GitHub App credentials. |
| `THALLY_OIDC_ISSUER` | Team sign-in | OpenID Connect issuer URL. |
| `THALLY_OIDC_CLIENT_ID` | Team sign-in | OIDC client identifier. |
| `THALLY_OIDC_CLIENT_SECRET` | Team sign-in | OIDC client secret. |

## Durable storage and analytics

| Variable | Required | Purpose |
| --- | --- | --- |
| `THALLY_DATABASE_URL` | Serverless persistence | Remote libSQL URL for settings, task state, and rate limits. |
| `THALLY_DATABASE_TOKEN` | With remote database | Authentication token for `THALLY_DATABASE_URL`. |
| `THALLY_ANALYTICS_DB_URL` | Serverless analytics | Remote libSQL URL for analytics events. |
| `THALLY_ANALYTICS_DB_TOKEN` | With analytics database | Authentication token for the analytics database. |
| `THALLY_STORAGE` | No | Set to `memory` to opt out of persistent general storage. |
| `THALLY_ANALYTICS_SECRET` | No | Separate internal analytics-ingest secret. |

## AI and agent limits

| Variable | Required | Purpose |
| --- | --- | --- |
| `ANTHROPIC_API_KEY` | Owner-powered AI | Production key for chat and documentation-agent operations. |
| `THALLY_TRIAL_ANTHROPIC_KEY` | No | Shared trial key used under strict limits when no owner key is present. |
| `THALLY_CHAT_RATE_PER_MIN` | No | Owner-tier chat requests per minute. |
| `THALLY_CHAT_RATE_PER_DAY` | No | Owner-tier daily limit; `0` means unlimited. |
| `THALLY_TRIAL_RATE_PER_MIN` | No | Trial requests per minute. |
| `THALLY_TRIAL_RATE_PER_DAY` | No | Trial requests per day per visitor. |
| `THALLY_TRIAL_DAILY_LIMIT` | No | Global trial requests per day. |
| `THALLY_MCP_RATE_PER_MIN` | No | Remote MCP request-rate override. |
| `THALLY_AGENT_MODEL` | No | Model override for documentation-agent runs. |

## Thally Track and GitHub

| Variable | Required | Purpose |
| --- | --- | --- |
| `THALLY_REPO_URL` | Sometimes | Docs repository Track dispatches to when `site.ts` has no repository URL. |
| `THALLY_TRACK_WEBHOOK_SECRET` | Manual webhook mode | HMAC secret shared with product-repository webhooks. |
| `THALLY_GITHUB_TOKEN` | Manual token mode | Fine-grained token for reading tracked pull requests and dispatching work. |
| `THALLY_GITHUB_APP_ID` | Manual App setup | GitHub App identifier. |
| `THALLY_GITHUB_APP_INSTALLATION_ID` | Manual App setup | Installation used to mint access tokens. |
| `THALLY_GITHUB_APP_PRIVATE_KEY` | Manual App setup | PEM private key. Preserve line breaks in the host's secret field. |
| `THALLY_AGENT_TOKEN` | Agent workflow | Token that can write to the docs repository and read configured product repositories. |
| `THALLY_DISPATCH_TOKEN` | Product repository workflow | Secret used to dispatch an update to the docs repository. |

Some managed automation variables are injected by Thally services or GitHub
Actions for one run. Do not set undocumented internal grant, task, or pull-
request metadata variables yourself.

## Verify configuration

After adding or changing variables, restart the development server or redeploy.
Then test the specific feature and check server logs without printing secret
values.
